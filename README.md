# Большая Зона — ReFix

Лаунчер и обновления сборки by SunChess для S.T.A.L.K.E.R. Тень Чернобыля.

**Статус 13.10.2026:** EXE версии 1.0 из релиза v2026.10.13.1 обнаруживается Microsoft Defender как Trojan:Win32/Bearfoos.A!ml. Не добавляйте его в исключения. Версия 1.1 с раздельными этапами обновления пока проверяется локально; исчезновение детекции не гарантируется, заключения Microsoft нет.

## Для игроков

Скачайте **ReFixLauncher.zip** из [последнего релиза](https://github.com/SunChessss/Bolshaya-Zona-ReFix/releases/latest).
Распакуйте два файла лаунчера в корень готовой сборки ReFix — рядом с `bin`, `gamedata` и `fsgame.ltx`.
Запускайте **ReFixLauncher.exe**. Также можно выбрать папку игры в самом лаунчере.

- При запуске проверяются обновления на GitHub. В версии 1.1 «Скачать обновление» только скачивает и проверяет пакет. «Просмотреть и установить» показывает папку, версию и файлы; установка начинается после отдельного подтверждения. Отмена оставляет игру без изменений.
- В «Дополнениях» можно выбрать весну или осень, минималистичный HUD и адаптацию NEW HUD.
- В «Настройках» доступны освещение, разрешение, оконный режим, синхронизация, текстуры, фильтрация, дальность, трава и гамма.
- Комфортный и предельный вес задаются отдельно. Скорость — множитель к исходному `walk_accel = 17`.
- Перед изменениями закройте игру. Сохранения и посторонние настройки не изменяются.

Требуется Windows 10/11 с .NET Framework 4.8. Не нужен аккаунт GitHub. Сам лаунчер пока обновляется вручную заменой файлов из нового ReFixLauncher.zip. EXE не подписан цифровым сертификатом.

## Обновления и восстановление

Патчи кумулятивные, от V20.2 Final. Каталог `launcher-manifest.json` находится в GitHub Releases вместе с архивами. Пакеты проверяются по SHA-256 и внутреннему MANIFEST.json до установки. Личные значения в `bz_lord.ltx` патчами не перезаписываются.

Лаунчер хранит состояние, кэш и резервные копии в `.refix-launcher` внутри игры. Не удаляйте эту папку, пока нужны возврат дополнений или восстановление. После прерванной установки незавершённая операция откатывается при следующем запуске. Перед обновлением активные дополнения снимаются и затем устанавливаются заново поверх новой основы.

Диагностический журнал версии 1.1: `.refix-launcher/operations.log`. Содержит время UTC, этапы скачивания, проверки, установки, ошибки и записи до/после замены файлов; журнал принудительно сбрасывается на диск. Это помогает установить последний завершённый этап при прерывании. Перед установкой SHA-256 пакета проверяется повторно. Журнал не отправляется в сеть.

Возврат дополнения восстанавливает файлы, сохранённые именно при его установке через лаунчер. Если ранее дополнения устанавливались вручную, исходное состояние означает эту ручную установку. Пункт «Осень — основа сборки» устанавливает известный осенний пакет явно.

Версия 1.2 распознаёт установленный патч по SHA-256 50 игровых файлов, даже после ручной распаковки, без истории лаунчера и без интернета. Встроены эталоны ReFix от 12.10 (до фикса статики) и 13.10.2026. При несовпадении показываются изменённые и отсутствующие файлы; запись в истории установки не подменяет проверку. Кнопка «Проверить установку» запускает её повторно. Проверяются файлы кумулятивного патча, а не все ресурсы полной игры. Неизвестным комбинациям файлов точный номер версии не присваивается.

В настройках версии 1.2 есть «Текст интерфейса игры»: исходный, крупный и очень крупный. Кнопка «Применить размер текста» переключает штатные атласы Arial/Letterica в `fonts.ltx`; размер меняется в окнах, использующих эти шрифты, после перезапуска игры. Заголовки на других шрифтах не меняются. В отдельных окнах крупный текст может обрезаться. Исходный файл сохраняется в `.refix-launcher/font-original.ltx`; возврат восстанавливает его побайтно. Если файл затем изменён вручную или другим дополнением, лаунчер откажется его перезаписывать. Запуск игры и её настройки доступны без сети.

## Разработчику

Исходники: `src/`. Сборка без внешних пакетов:

```powershell
.\build.ps1
.\test.ps1
```

Для формирования нового релиза положите проверенные `Bolshaya_Zona_ReFix_Fixes.zip` и `Bolshaya_Zona_ReFix_Optional.zip` в отдельную папку:

```powershell
python package.py --release-dir C:\path\to\release --version 2026.10.13.2 --tag v2026.10.13.2
```

Создайте GitHub Release с соответствующим тегом и загрузите **все** файлы из `artifacts/<tag>/`. Сначала прикрепите файлы, затем публикуйте релиз. Отметьте его последним стабильным. Каталог и имена пакетов формируются автоматически; токены в лаунчер не включаются. Выпущенные теги и пакеты не заменяйте — публикуйте следующий номер.

Тесты проверяют установку, сохранность личного веса, переключение дополнений, новую основу после обновления, откат и восстановление после обрыва, повреждённые пакеты и опасные пути. Ручная проверка интерфейса и запуска игры дополняет эти тесты.

Проверка опубликованного релиза на отдельной тестовой копии игры:

```powershell
.\test-release.ps1 -GameRoot C:\path\to\disposable-test-copy
```

Она скачивает каталог и все игровые пакеты с GitHub, устанавливает хотфикс, по очереди включает и снимает каждое дополнение, сверяет файлы и сохранность личных настроек. Хотфикс остаётся установленным; дополнения возвращаются в исходное состояние. Используйте копию без ранее активированных через лаунчер дополнений.

Полная игра здесь не размещается. Игровые ресурсы принадлежат их авторам; репозиторий содержит исходники лаунчера, релизы — исправления и опциональные пакеты сборки.
