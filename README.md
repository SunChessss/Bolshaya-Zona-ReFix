# Большая Зона — ReFix

Лаунчер и обновления сборки «Большая Зона» by SunChess для S.T.A.L.K.E.R. Тень Чернобыля.

| | |
|---|---|
| Текущая сборка исправлений | **2026.10.30.1** (кумулятивная от V20.2 Final) |
| Текущий лаунчер | **1.10.0** |
| Скачать лаунчер | [**ReFixLauncher.zip**](https://github.com/SunChessss/Bolshaya-Zona-ReFix/releases/latest/download/ReFixLauncher.zip) (прямая ссылка, всегда последняя версия) |
| Все файлы | [последний релиз](https://github.com/SunChessss/Bolshaya-Zona-ReFix/releases/latest) |

Новая игра для установки исправлений не требуется: закройте игру, нажмите «Обновить» в лаунчере (или распакуйте Fixes в корень сборки).

**О Defender:** EXE версии 1.0 (релиз v2026.10.13.1) Microsoft Defender определял как Trojan:Win32/Bearfoos.A!ml. Не используйте 1.0 и не добавляйте лаунчер в исключения. Версии 1.1–1.6.0 локальными проверками не детектировались; заключения Microsoft нет, отсутствие будущих срабатываний не гарантируется.

## Для игроков

Скачайте **[ReFixLauncher.zip](https://github.com/SunChessss/Bolshaya-Zona-ReFix/releases/latest/download/ReFixLauncher.zip)**: ссылка постоянная и всегда ведёт на архив из последнего релиза.
Распакуйте два файла лаунчера в корень готовой сборки ReFix — рядом с `bin`, `gamedata` и `fsgame.ltx`.
Запускайте **ReFixLauncher.exe**. Также можно выбрать папку игры в самом лаунчере.

- При запуске проверяются обновления на GitHub. В версии 1.1 «Скачать обновление» только скачивает и проверяет пакет. «Просмотреть и установить» показывает папку, версию и файлы; установка начинается после отдельного подтверждения. Отмена оставляет игру без изменений.
- В «Дополнениях» можно выбрать весну, лето или осень, минималистичный HUD, адаптацию NEW HUD и «Оптимизацию текстур» (лаунчер 1.7; предлагается автоматически, занимает около 1,4 ГБ плюс резервная копия исходных текстур в `.refix-launcher/bases`).
- В «Настройках» доступны освещение, разрешение, оконный режим, синхронизация, текстуры, фильтрация, дальность, трава и гамма.
- Комфортный и предельный вес задаются отдельно. Скорость — множитель к исходному `walk_accel = 17`.
- «Дроп лута с трупов NPC» (лаунчер 1.6, патч 2026.10.15.4): как в сборке / уменьшенный / как в оригинальном ТЧ / мусорщик. Выбор записывается в `gamedata/config/bz_lord.ltx` (`[bz_loot] preset`) и читается игрой при загрузке.
- «Собрать данные о вылете» (лаунчер 1.10): при вылете без лога включает запись дампов Windows для `XR_3DA.exe` (ключ `HKLM\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps\XR_3DA.exe`, мини-дампы в `%LOCALAPPDATA%\CrashDumps`) и собирает на Рабочий стол архив с дампами, логами, отчётами `.wer`, событиями «Ошибка приложения» и последним сейвом. Архив никуда не отправляется.
- Перед изменениями закройте игру. Сохранения и посторонние настройки не изменяются.

Требуется Windows 10/11 с .NET Framework 4.8. Не нужен аккаунт GitHub. EXE не подписан цифровым сертификатом.

Начиная с версии 1.3, при проверке обновлений выбранной сборки проверяется и версия самого лаунчера. Если доступна новая, появляется кнопка «Обновить лаунчер». После подтверждения архив скачивается с GitHub Releases, проверяется по размеру и SHA-256. Лаунчер закрывается, вспомогательный процесс заменяет только EXE и его конфигурацию и открывает лаунчер с выбранной папкой игры. Для перехода с версий 1.0–1.2 нужно один раз распаковать 1.3 вручную.

Промежуточные файлы лежат в `.refix-self-update` рядом с EXE; резервные копии и журнал — в `.refix-launcher`. Нужны права записи в папку лаунчера. Ошибка записи вызывает транзакционный откат; проверка успешной работы новой версии после запуска пока не выполняется. Резервные копии остаются для восстановления. Если защитник блокирует запуск, не отключайте защиту и не добавляйте исключения.

## Обновления и восстановление

Патчи кумулятивные, от V20.2 Final. Каталог `launcher-manifest.json` находится в GitHub Releases вместе с архивами. Пакеты проверяются по SHA-256 и внутреннему MANIFEST.json до установки. Личные значения в `bz_lord.ltx` патчами не перезаписываются.

Лаунчер хранит состояние, кэш и резервные копии в `.refix-launcher` внутри игры. Не удаляйте эту папку, пока нужны возврат дополнений или восстановление. После прерванной установки незавершённая операция откатывается при следующем запуске. Перед обновлением активные дополнения снимаются и затем устанавливаются заново поверх новой основы.

Диагностический журнал версии 1.1: `.refix-launcher/operations.log`. Содержит время UTC, этапы скачивания, проверки, установки, ошибки и записи до/после замены файлов; журнал принудительно сбрасывается на диск. Это помогает установить последний завершённый этап при прерывании. Перед установкой SHA-256 пакета проверяется повторно. Журнал не отправляется в сеть.

Возврат дополнения восстанавливает файлы, сохранённые именно при его установке через лаунчер. Если ранее дополнения устанавливались вручную, исходное состояние означает эту ручную установку. Пункт «Осень — основа сборки» устанавливает известный осенний пакет явно.

Версия 1.2 распознаёт установленный патч по SHA-256 50 игровых файлов, даже после ручной распаковки, без истории лаунчера и без интернета. Встроены эталоны ReFix от 12.10 (до фикса статики) и 13.10.2026. При несовпадении показываются изменённые и отсутствующие файлы; запись в истории установки не подменяет проверку. Кнопка «Проверить установку» запускает её повторно. Проверяются файлы кумулятивного патча, а не все ресурсы полной игры. Неизвестным комбинациям файлов точный номер версии не присваивается.

В настройках версии 1.2 есть «Текст интерфейса игры»: исходный, крупный и очень крупный. Кнопка «Применить размер текста» переключает штатные атласы Arial/Letterica в `fonts.ltx`; размер меняется в окнах, использующих эти шрифты, после перезапуска игры. Заголовки на других шрифтах не меняются. В отдельных окнах крупный текст может обрезаться. С патчем 2026.10.15.3 и лаунчером 1.5.1 крупные пресеты используют атласы `ui_font_letter_25r` / `ui_font_letter_18r` (шрифт Inter, OFL; без патча — прежние штатные).

«Масштаб интерфейса» (лаунчер 1.5, патч 2026.10.15.2 и новее): «крупный» копирует альтернативные файлы окон из `gamedata/config/ui_large` поверх `gamedata/config/ui` (инвентарь, торговля, ящики и трупы, главное меню); исходные файлы сохраняются побайтно в `.refix-launcher/ui-original` и восстанавливаются пунктом «исходный». Если файлы окон затем изменены вручную или дополнением, лаунчер покажет «Изменён вне лаунчера» и откажется их перезаписывать. Исходный файл сохраняется в `.refix-launcher/font-original.ltx`; возврат восстанавливает его побайтно. Если файл затем изменён вручную или другим дополнением, лаунчер откажется его перезаписывать. Запуск игры и её настройки доступны без сети.

## Разработчику

Исходники: `src/`. Сборка без внешних пакетов:

```powershell
.\build.ps1
.\test.ps1
```

Для формирования нового релиза положите проверенные `Bolshaya_Zona_ReFix_Fixes.zip` и `Bolshaya_Zona_ReFix_Optional.zip` в отдельную папку:

```powershell
python package.py --release-dir C:\path\to\release --version 2026.10.14.4 --tag v2026.10.14.4 `
  --notes-file notes.txt --addons-from v2026.10.13.1 --launcher-from v2026.10.14.3
```

С версии 1.4 эталоны сборок для «Проверить установку» уходят в каталог релиза (`launcher-manifest.json`, поле `profiles`): для нового патча добавьте профиль первым в `src/InstallProfiles.json` (version, title, patchHash = SHA-256 Fixes, files без `bz_lord.ltx`). `--launcher-from` ссылается на релиз с текущим лаунчером, EXE не пересобирается. Новый лаунчер (только при изменении кода): поднять `VersionString`, `build.ps1`, `test.ps1`, `package.py` без `--launcher-from`.

Создайте GitHub Release с соответствующим тегом и загрузите **все** файлы из `artifacts/<tag>/`. Сначала прикрепите файлы, затем публикуйте релиз. Отметьте его последним стабильным. Каталог и имена пакетов формируются автоматически; токены в лаунчер не включаются. Выпущенные теги и пакеты не заменяйте — публикуйте следующий номер.

Тесты проверяют установку, сохранность личного веса, переключение дополнений, новую основу после обновления, откат и восстановление после обрыва, повреждённые пакеты и опасные пути. Ручная проверка интерфейса и запуска игры дополняет эти тесты.

Проверка опубликованного релиза на отдельной тестовой копии игры:

```powershell
.\test-release.ps1 -GameRoot C:\path\to\disposable-test-copy
```

Она скачивает каталог и все игровые пакеты с GitHub, устанавливает хотфикс, по очереди включает и снимает каждое дополнение, сверяет файлы и сохранность личных настроек. Хотфикс остаётся установленным; дополнения возвращаются в исходное состояние. Используйте копию без ранее активированных через лаунчер дополнений.

Полная игра здесь не размещается. Игровые ресурсы принадлежат их авторам; репозиторий содержит исходники лаунчера, релизы — исправления и опциональные пакеты сборки.
